# Frontend copy

The implementation catalog is `copy/src/en.json`. The original combined workspace also keeps a planning catalog in sync. Both the app and the review embed use the shared copy package.

The user's writing sample sets the conversational direction: explain a concept when it first matters, connect the sentences, and tell the reader why a detail affects them. Its subject matter and distinctive expressions are not reused.

The rewrite replaces slogans with the actual sequence: deposit tokens to receive vault shares, redeem shares to withdraw the underlying tokens, swap those tokens into the settlement token, and enforce the minimum that reaches the account. It explains quotes as estimates, signed minimums as requirements, and fees as a separate possible cost of failure. Deposits do not imply a promised yield or an enforced minimum share issuance.

Controls name their action. Errors explain the problem and the next useful step. Unknown results remain unknown. Unacknowledged submissions explain that the signed transaction is held in memory and must be retried without creating another transaction. Wallet detection and connection each have their own status.

Contractions and a little humour are appropriate in introductory or empty states. Signing, balances, fees and failures use direct factual language. Protocol names, exact identities, amounts and ordinary interface controls retain their literal meaning.
